# Функции за пределами MVP 1.0

Этот перечень фиксирует границы задания. Код интерфейса пока недоступен; перечисленные изменения ещё не выполнены.

| Функция | Действие после получения исходников |
| --- | --- |
| GPS и автоматическое прибытие | Убрать из активного сценария вызовы геолокации. Прибытие отмечает пользователь; показать «Прибытие отмечено вручную». |
| ИИ-гид | Убрать пункт навигации и виджеты, отключить обращения к внешнему API. |
| Коллекция достопримечательностей | Убрать из основной навигации, исключить зависимость встреч от коллекции. |
| Погода и погодные поправки ETA | Убрать виджеты и запросы, исключить расчёты из MVP. |
| Push-уведомления | Не запрашивать разрешение и не регистрировать push-подписки. Проверить существующий service worker перед изменением. |

Полезный изолированный код можно сохранить для следующего этапа. Пользовательские данные не удалять. Неиспользуемые импорты исключить из активной сборки только после анализа их зависимостей.

В чате MVP предусмотрен только текст: голос, видео, файлы, ИИ и push не входят в реализацию.
